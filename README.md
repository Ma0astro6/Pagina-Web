# Cerro

Un juego para el celular: apilas casas cerro arriba, como en los cerros de Valparaíso.

Abre `index.html` en el navegador. En el teléfono, un toque suelta la casa.

## Cómo se juega

La casa de arriba se mueve sola. Tócala cuando calce con la de abajo.

- Si cae justo, no se achica y armas racha.
- Si cae corrida, se corta lo que sobra.
- Si no alcanza a la de abajo, se acaba la partida.

El récord queda guardado en ese teléfono. La tecla M (o el ícono de arriba a la derecha) corta el sonido. En el computador también sirve la barra espaciadora.
